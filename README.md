## Задание 1: Реализация стека

### Описание
Реализация абстрактного типа данных "Стек" (LIFO - Last In, First Out).

### Класс Stack

#### Методы
- `is_empty()` - проверка стека на пустоту. Возвращает True или False
- `push(element)` - добавляет новый элемент на вершину стека. Ничего не возвращает
- `pop()` - удаляет верхний элемент стека. Возвращает удаленный элемент
- `peek()` - возвращает верхний элемент стека без удаления. Стек не меняется
- `size()` - возвращает количество элементов в стеке

## Задание 2: Проверка сбалансированности скобок
### Описание
Используя класс Stack, реализована функция для проверки сбалансированности скобок в строке.

Принцип работы
Открывающие скобки (, [, { помещаются в стек

При встрече закрывающей скобки проверяется соответствие с верхним элементом стека

Если стек пуст или скобки не соответствуют - строка несбалансирована

Примеры сбалансированных строк
(((([{}]))))
[([])((([[[]]])))]{()}
{{[()]}}

Примеры несбалансированных строк
}{}
{{[(])]}}
[[{())}]

Программа выведет результаты проверки всех тестовых случаев.
